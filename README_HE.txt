OLD SCHOOL HIP HOP MAKER — פרויקט מקור ראשוני

מה יש בגרסה הזו:
- תוסף VST3 בסיסי ל-Windows המבוסס על JUCE.
- טעינת קובץ אודיו (WAV / AIFF / FLAC / OGG).
- חלוקה שווה של ההקלטה ל-16 מקטעים.
- 16 כפתורי PAD צבעוניים.
- שליטה דרך MIDI: תווים 36 עד 51 מפעילים את הפדים 1 עד 16.

מה עדיין לא קיים:
- זיהוי אוטומטי של טרנזיינטים.
- גרירת גבולות חיתוך ידנית ותצוגת waveform אמיתית.
- Reverse, Pitch, אפקטים ושמירת Kits.
- אופטימיזציה מלאה לעבודה בזמן אמת.

בנייה:
הפרויקט כולל GitHub Actions לבנייה בענן. יש להעלות את תוכן התיקייה למאגר GitHub,
להיכנס ללשונית Actions, לאשר הפעלת Workflows אם תתבקש, ולהריץ Build Windows VST3.
התוסף יופיע כ-Artifact להורדה לאחר הצלחת הבנייה.

דרישות:
- CMake 3.22 ומעלה בסביבת הבנייה.
- JUCE נמשך אוטומטית על ידי ה-Workflow.
- JUCE מופץ ברישיון GPLv3 או ברישיון מסחרי; יש לבדוק התאמת רישוי לפני הפצה.
